# Plaid setup for Money Momentum

This public source copy includes no Plaid credentials. Configure your own Sandbox environment first. Live access is not established by cloning this repository. The account holder must authorize each bank connection.

1. Create the app in the Plaid Dashboard. Start in Sandbox. Request Transactions; do not enable payment or transfer products.
2. In Plaid allowed redirect URIs add exactly https://money-momentum.honeyamber64.chatgpt.site/ including the final slash.
3. Configure PLAID_CLIENT_ID, PLAID_SECRET, PLAID_ENV, and PLAID_TOKEN_ENCRYPTION_KEY through Sites managed environment secrets. Never paste values into chat, commit them, or put them in browser code. PLAID_TOKEN_ENCRYPTION_KEY must be 32 cryptographically random bytes encoded as 64 hex characters. Keep this key stable; rotating it requires reconnecting accounts unless tokens are re-encrypted first.
4. Use PLAID_ENV=sandbox for sample banks. Test Link, OAuth return, mapping accounts, refreshing transactions, and disconnecting. Sandbox data is explicitly labeled fictional.
5. Obtain Plaid live/Trial access before setting PLAID_ENV=production and using a production secret. Verify Bank of America and Credit Karma availability for the requested products. The account holder must authorize through Plaid; never collect bank credentials in this app.
6. Republish to apply environment changes. Bank tokens stay encrypted server-side, scoped to the signed-in Sites user; no bank access tokens are sent to the browser.

The app supports read-only linking, current/reported available balances, dynamic cards named from each connected institution and account type, manually requested transaction sync, pending/posting replacement, and bank disconnect with stored-data cleanup. It does not initiate payments, continuously poll banks, or overwrite the manual log. Plaid transaction data can lag or be unavailable; the UI reports missing available balances without inventing values.

Local frontend sources now live in public/. dist/ is generated by the server build. Database schema is db/schema.ts; migration files under drizzle/ are immutable after application.
